# Documentaries Research Landing Page

A sleek, content-driven landing page for documentary research — showcasing documentary topics, research collections, and curated film content in a clean, modern layout.

## Features

- Landing page layout for documentary research content
- Responsive, mobile-friendly design
- Sections for featured documentaries / research topics
- Clean typography and visual hierarchy

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Quick Start

No build step required — it's a plain static site.

1. Clone the repository:
   ```bash
   git clone https://github.com/girishlade111/Documentaries-Research-Landing-Page.git
   ```
2. Open `index.html` in any browser, or serve the folder with any static server:
   ```bash
   npx serve .
   ```
